# Lernkasten DIN A7 – NgarumaVTC

Leitner-Lernkasten mit fünf Fächern für DIN-A7-Karteikarten, Serie von 120 Stück. Zwei Varianten:

- [`sperrholz/`](sperrholz/README.md): 6 mm Sperrholz, CNC-gefräst bei M+M Kappeln, verleimt in Ngaruma
- [`karton/`](karton/README.md): braune Wellpappe, fünf Innenkästen mit Papierwinkeln plus aufgeklebter Außenkasten, dazu eine Schneidlade aus Holz für die Tischlerwerkstatt in Ngaruma

## Anleitung für die Schülerinnen

[`lernkasten_anleitung.org`](lernkasten_anleitung.org): wie man mit dem Lernkasten lernt (Leitner-Prinzip, Lernplan, Blankokarten im Unterricht, offene Fragen klären), in einfacher Sprache ab Klasse 5. PDF in [`build/lernkasten_anleitung.pdf`](build/lernkasten_anleitung.pdf), gebaut mit `./build_anleitung.sh`.
